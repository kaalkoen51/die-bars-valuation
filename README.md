# 🏢 Die Bars — Commercial Property Investment Valuation App

Interactive investment analysis tool for **Die Bars**, a multi-unit retail commercial property in Bredasdorp, Western Cape, South Africa.

## Features
- 📋 Property overview & acquisition cost breakdown
- 💰 Full tenant schedule & income analysis
- 📊 Income capitalisation valuation with traffic-light health checks
- 🏦 Bond finance calculator with waterfall cashflow charts
- 📈 10-year DCF projection with exit analysis, IRR & NPV
- 🔄 Multi-scenario comparison (different financing structures)
- ⚠️ Sensitivity analysis with tornado diagrams, break-even & heat maps

## Run Locally
```bash
pip install -r requirements.txt
streamlit run die_bars_valuation_app.py
```

## Built With
- [Streamlit](https://streamlit.io/)
- [Plotly](https://plotly.com/)
